# Itinerary Import — Requirements

## Functional Requirements (MoSCoW)

### Must Have

- [ ] **FR-1** As a traveller, I want to import an itinerary, so that I don't retype it.
  - Given a valid itinerary file, When I import it, Then its legs appear in my trip.
- [ ] **FR-2** As a traveller, I want import errors explained, so that I can fix the file.

## Non-Functional Requirements

- **NFR-1** (Must) Reliability: a failed import leaves no partial trip data behind.
