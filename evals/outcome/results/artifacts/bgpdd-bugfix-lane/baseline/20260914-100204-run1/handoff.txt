## What I did

**Root cause:** `src/coupons.js:31` — `applyCoupon(code)` called `code.toUpperCase()` unconditionally. With no `coupon` in the body, `body.coupon` is `undefined`, so that threw a bare `TypeError`. `src/server.js:67` only maps errors carrying an integer `status` to a client error, so the TypeError fell through to the generic 500.

**Fix** (4 lines, `src/coupons.js`, the only file changed):

```js
function applyCoupon(code) {
  // The coupon field is optional: an order without one prices at full.
  if (code === undefined || code === null) {
    return { coupon: null, discountPercent: 0 };
  }
  const normalized = code.toUpperCase();
```
